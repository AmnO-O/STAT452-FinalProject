This section addresses the first research question: how accurately can we predict the salary of a Data Science professional worldwide, and which factors drive income levels? We model salary_in_usd through its natural logarithm log_salary, because the exploratory analysis showed a strongly right-skewed distribution with a handful of legitimate executive-level salaries; working on the log scale accommodates that skew without discarding real observations, and it gives coefficients a convenient percentage interpretation.

Seven model specifications are constructed and their assumptions tested: a multiple linear regression, first with all available predictors and then reduced by stepwise selection; a polynomial regression that lets the numeric predictors bend away from a straight line; Ridge, LASSO, and their elastic-net mixture with a cross-validated mixing weight, which stabilize estimates when many dummy variables share the workload; and a final linear model fitted on the Box–Cox-optimal power transform \(\text{salary}^{\lambda}\). All fitting, tuning, and assumption testing use the training data only; the held-out records are kept untouched here and are formally scored and compared in Task 6.

4 Continuous Salary Regression Modeling

4.1 Training and testing partitions

Model quality is judged on observations not seen during fitting, so we split the 565 cleaned records into training (80%) and test (20%) sets. The first research question asks how accurately salaries can be predicted globally and which factors drive income across the whole sample, so every observation era has an equal chance of being held out: a single random 80 : 20 split of the 565 records assigns 452 rows to training and 113 to test, preserving the global mix of years, roles, and locations in both partitions. No temporal or year-aware constraint is imposed, because the goal is a model for the population of data-science salaries as a whole, not a forecast of any single future year.

The draw is checked so that rare categories (contract and freelance employment have 5 and 4 records dataset-wide) stay represented in training; the fixed seed makes the split fully reproducible.

4.2 Multiple Linear Regression

We build the regression the way an analyst should: start from the simplest defensible choice — an ordinary linear model on the raw dollar salary — confront it with the classical assumptions, let a Box–Cox analysis select a better response scale, and then verify that the corrected model genuinely behaves better. Only after the response scale is settled do we refine the model and interpret its coefficients.

A reference model on raw dollars

All working models in this section share the same right-hand side — experience level, job category, employment type, company size, grouped employer location, remote-work ratio, survey year, and is_local (1 when the employer country matches the employee’s country of residence, 0 otherwise). The reference version below regresses the raw dollar amount on the demographic design without is_local, purely to choose the Box–Cox response scale; every working model that follows (log, power, and penalized) carries the full set including is_local, so the residence-match signal competes fairly with the other predictors.

Diagnostic checking of the reference model

The four base residual plots, formal normality tests, a Breusch–Pagan test for homoskedasticity, and Cook’s distance (influence of single observations) are applied so that every assumption is tested, never assumed.

diag_row <- function(label, mod) {
  sw <- shapiro.test(resid(mod))
  jb <- tseries::jarque.bera.test(resid(mod))
  bp <- lmtest::bptest(mod)
  tibble(response       = label,
         Shapiro_p      = signif(sw$p.value, 3),
         Jarque_Bera_p  = signif(jb$p.value, 3),
         BP_stat        = round(unname(bp$statistic), 1),
         BP_p           = signif(bp$p.value, 3),
         Max_Cooks_D    = round(max(cooks.distance(mod)), 3))
}
diag_raw <- diag_row("salary_in_usd", ols_raw)
diag_raw
par(mfrow = c(2, 2)); plot(ols_raw); par(mfrow = c(1, 1))

Every check fails. Residual normality is rejected at astronomical significance (p ≈ 1.3·10⁻²¹), errors are heteroskedastic (BP = 41.6, p = 0.010), and the largest Cook’s distance reaches 0.18 — a handful of executive-level records visibly dominate the fitted line. An untransformed linear model is therefore not a trustworthy basis for inference or prediction.

Choosing the response scale: Box–Cox analysis

The Box–Cox family asks which power \(\text{salary}^{\lambda}\) makes the linear model most consistent with its assumptions:

bc <- MASS::boxcox(ols_raw, lambda = seq(-2, 2, length = 100), plotit = TRUE)

lambda_hat <- bc$x[which.max(bc$y)]
## Profile-likelihood 95% confidence interval for lambda
cut_off  <- max(bc$y) - qchisq(0.95, 1) / 2
lambda_ci <- range(bc$x[bc$y >= cut_off])
cat("Box-Cox optimal lambda:", round(lambda_hat, 3), "\n")
## Box-Cox optimal lambda: 0.263
cat("95% CI: [", round(lambda_ci[1], 3), ",", round(lambda_ci[2], 3), "]\n")
## 95% CI: [ 0.222 , 0.343 ]

The likelihood peaks at \(\hat\lambda \approx 0.26\), with a 95% profile-likelihood interval \([0.22,\ 0.34]\) that excludes both special cases: \(\lambda = 1\) (raw dollars, rejected above) and \(\lambda = 0\) (the log). Formally, the data prefer an intermediate power. We adopt ln(salary) as the working response for its interpretable percentage coefficients, and give \(\text{salary}^{0.26}\) the identical battery of assumption tests below; whether the intermediate power rivals ln(salary) out of sample is deferred to Task 6, which owns the held-out comparison.

The regression on ln(salary)

\[\ln(\text{salary}_i) = \beta_0 + \beta_1\,\text{experience}_i + \beta_2\,\text{role}_i + \beta_3\,\text{contract type}_i + \beta_4\,\text{company size}_i + \beta_5\,\text{employer location}_i + \beta_6\,\text{remote ratio}_i + \beta_7\,\text{year}_i + \beta_8\,\text{is\_local}_i + \varepsilon_i\]

Location enters through the grouped employer-country variable plus a single is_local flag that records whether the employer country matches the employee’s country of residence. The full employee-residence dummies are deliberately left out: for the largely non-remote workforce the two countries coincide, and carrying both sets of dummies would introduce near-duplicate predictors whose inflated variances distort every coefficient’s standard error. The one-column indicator captures the essence of the residence signal at negligible collinearity cost.

Side by side, the log transformation earns its place: the Shapiro–Wilk p-value rises from 1.3·10⁻²¹ (raw dollars) to 3.0·10⁻¹³ — a roughly two-hundred-and-thirty-million-fold improvement in consistency with normality — and the maximum Cook’s distance falls by a factor of about three (0.180 → 0.060), so no single record any longer dictates the fit. The Box–Cox-optimal power behaves comparably (normality p = 1.9·10⁻⁸, maximum Cook’s distance 0.072) without clearly outdoing the log on any criterion, and — like the log scale — its Breusch–Pagan statistic remains significant (42.2, p = 0.012; log: 54.7, p = 3.4·10⁻⁴; raw: 41.6, p = 0.010). Two conclusions follow. First, the transformations repair the worst failures of the raw-dollar model, but residual non-normality and heteroskedasticity persist — the rejections trace to the thin cluster of very low salaries documented in the EDA — so robust inference is required regardless of scale. Second, because neither transformation attains clean diagnostics on every criterion, the working response is chosen by interpretability — ln(salary) and its percentage coefficients, used throughout this section — while Task 6 holds the empirical verdict on which scale predicts best. On the collinearity side, all df-adjusted GVIFs lie between 1.03 and 1.26 — far under any common threshold — confirming that the single location route plus the sparse is_local flag avoided redundancy.

Refining the model by AIC

The full model contains two linear trend terms (remote_ratio, work_year) whose usefulness a parsimonious model should justify. Stepwise selection in both directions, guided by Akaike’s information criterion, removes exactly the survey-year term while keeping remote_ratio, all five factor blocks, and the is_local flag: the AIC improves from 654.5 to 652.5 at unchanged adjusted R² (0.638), i.e., the simpler model predicts equally well without the year trend.

Four patterns stand out.

Experience dominates. Relative to an entry-level professional, mid-level colleagues earn about 24% more, seniors about 65% more, and executives about 157% more — a steep, strictly increasing gradient that makes seniority the single strongest career-side lever in the data.

Role matters within the field. Against the Data-Analyst baseline, moving into engineering (+33%) or science (+39%) pays moderately; specializing in machine learning/AI (+50%), leading teams (+59%), or research (+70%) pays substantially more. The heterogeneous “Other” category is statistically indistinguishable from analysts, which supports keeping it separate rather than forcing it into another family.

Contract structure shapes pay. Part-time (−67%) and freelance (−66%) arrangements earn far less than full-time contracts, consistent with partial-year or project-based engagement; contract work shows a positive but unreliable premium (+31%), unsurprising given only five such records.

Residence-match carries its own premium. Being employed where you live is worth roughly 51% more than an otherwise identical posting at an overseas employer (p = 2·10⁻⁶ ordinary, p = 0.0020 robust) — the regression’s confirmation that the cross-border gap Task 6 finds on the same split is a real structural feature, not an artifact of which countries appear.

Geography sets the level. Holding profession and residence-match constant, a US-based employer pays roughly 155% above the rest-of-world baseline — by far the largest single effect in the model — with Canada (+88%), Great Britain (+69%), Germany (+68%) and France (+37%) forming a clear second tier, while India-based employers pay about 52% below it. Spain is indistinguishable from the baseline. Company size matters less: large firms pay about 35% more than small ones (p < 0.001); medium firms sit at +17%, significant only on the ordinary errors (p = 0.030 ordinary, p = 0.083 robust).

4.3 Polynomial Regression

Stepwise selection dropped the survey-year trend but kept remote_ratio; that raises a subtler question: is the remaining trend relationship curved? Polynomial regression answers it by allowing remote_ratio and work_year each to bend instead of following a straight line. Both variables take exactly three distinct values (0/50/100 and 2020/2021/2022), so degree 3 is not identifiable; degree 2 is the ceiling and effectively lets every level carry its own effect. We compare the linear and quadratic specifications with the nested F-test.

base_terms <- setdiff(attr(terms(ols_step), "term.labels"), c("remote_ratio", "work_year"))
base_formula_str <- paste("log_salary ~", paste(base_terms, collapse = " + "))

  f <- as.formula(paste0(base_formula_str,
                          " + poly(remote_ratio, ", degree, ")",
                          " + poly(work_year, ", degree, ")"))
  lm(f, data = train)
}

Out of sample the choice matters, but on the training data the quadratic specification is not supported: the F-test fails to reject the purely linear form (F = 2.48, p = 0.085), adjusted R² barely edges up from 0.638 to 0.640, and the RESET test finds no remaining functional-form misspecification on the selected degree-1 model (F = 1.99, p = 0.138). In substantive terms there is no evidence that fully-remote and fully on-site arrangements sit off the straight line connecting the extremes — the 50% hybrid point behaves broadly like the average of the two ends — so the parsimonious linear version is carried forward as the polynomial candidate for Task 6.

4.4 Ridge and LASSO Regression

Ordinary least squares treats all 21 columns as free parameters. Shrinkage methods trade a little bias for variance reduction and, in the LASSO’s case, automatic variable selection — a useful cross-check on the stepwise route. They require standardized inputs: all four numeric predictors are z-scored with training means and standard deviations, applied unchanged to the test records.

## Training-only z-scaling of every numeric input; the identical transform
## is applied to test.
tr_scale <- function(col) {
  m <- mean(train[[col]]); s <- sd(train[[col]])
  list(train = (train[[col]] - m) / s, test = (test[[col]] - m) / s)
}
for (col in c("exp_level_ord", "company_size_ord", "remote_ratio", "work_year")) {
  sc <- tr_scale(col)
  train[[paste0(col, "_ts")]] <- sc$train
  test[[paste0(col, "_ts")]]  <- sc$test
}

This task constructs the candidate models, verifies their assumptions, and interprets the drivers on the training data; formal scoring of the held-out records and the final model choice belong to Task 6. To close the modeling here, the table below summarizes how well each specification fits the 452 training rows. fit_row <- function(model, fit, y, n_coef, aic_val) {
  n    <- length(y)
  rss  <- sum((y - fit)^2)
  r2   <- 1 - rss / sum((y - mean(y))^2)
  adj  <- 1 - (1 - r2) * (n - 1) / (n - n_coef - 1)
  tibble(model = model,
         R2     = signif(r2, 4),
         adj_R2 = signif(adj, 4),
         n_par  = n_coef,
         AIC    = aic_val)
}

Three points follow. First, the stepwise-reduced model matches the full model on training data — equal adjusted R² (0.638) at a slightly lower AIC (652.5 vs 654.5) with one fewer parameter — so the pruning costs no in-sample fit while removing the marginal survey-year trend, the qualitative conclusion of Section 4.2. Second, the regularized fits show essentially identical training R² to the OLS variants (all in the range 0.651–0.657), as expected: shrinkage buys stability rather than in-sample fit, and their advantage, if any, materializes out of sample — which Task 6 measures. Third, adjusted R² falls below R² by only a small margin (about 0.02), because the models’ predictor count is modest relative to 452 training rows, so none of the candidates is badly over-parameterized in sample. In short, on the training data the candidate models are nearly indistinguishable in fit; their separation must come from held-out performance, which Task 6 evaluates.
